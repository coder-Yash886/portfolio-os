# Portfolio OS

Interactive desktop-style portfolio for **Yash** ([coder-Yash886](https://github.com/coder-Yash886)).

Inspired by the OS-portfolio idea — built as an original **teal / slate** desktop shell (not an Ubuntu clone).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Zustand (window manager)
- Framer Motion (animations — upcoming)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
